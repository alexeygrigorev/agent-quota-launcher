# Bounded useful launcher v0.1
Purpose: a head submits an independently useful, owned task. Launcher chooses a currently eligible healthy provider, reserves capacity and ownership, starts a genuinely bound worker, and records what actually happened. No utilization make-work.

Implement a usable Python 3 stdlib CLI package `python3 -m launcher` without installs/builds. Use JSON config and SQLite durable state, atomic transactions plus flock launch lock. Subcommands init, submit, plan, run, status, complete/accept, report; names may vary but document exact runnable examples. Plan is always dry-run and never represented as live execution.

Tasks require stable id/idempotency key, goal, owner/head, cwd, exclusive owned paths (resolve real paths and reject traversal), task type, model requirements, bounded timeout, first-action artifact path, expected result artifact path, retries <=2 with backoff. Repeating same key/same payload returns original; conflict key/payload fails. Duplicate live overlapping path ownership must fail. Shared state root must coordinate tasks even across cwd. Never steal a lease merely because time elapsed: expired+unknown stays needs_reconciliation until native child death confirmed. Use deterministic aplexer tag/run id and reconcile ambiguous launch result rather than rerun.

Provider adapters: Grok (grok -p --model grok-4.6 --effort high --permission-mode auto), Antigravity via agy OAuth (env strip GEMINI_API_KEY/GOOGLE_API_KEY, -p --print-timeout 0), verified zcodex coding plan ordinary quota, optional Go routes when exact entitlements verified. Codex always exact protected wrapper, Claude opt-in sparse, Copilot hard excluded. Fetch fresh `quse --json` at each actual admission; normalized provider status/error/window percentages must fail closed when unknown/invalid/stale. Any known relevant Codex window <=15 or limit flag fails even if another window ample. Other providers no exhausted relevant window. Exclude free OpenCode routes whose Go balance cannot prove entitlement. Allowlisted exact executable/argv with no arbitrary shell parsing. Config route evidence has model, command/version, entitlement source, checked_at, expires_at, verified or unknown health; missing/stale fails closed. Record runtime actual model where observed, do not treat requested model as measured.

Rank eligible candidates using task fit, health/outcome evidence, quota headroom, reset horizon and confirmed promotional window. Randomness only weighted among eligible choices, record probabilities/seed selection for audit. Saturate reset-pressure bonus so small nearly empty window cannot dominate; preserve long-window bottleneck and task fit. Unknown reset != immediate reset. Grok/zai preferred when useful quota would expire; Claude/Codex sparing; Ant available. Promotion ONLY verified ZCode >=3.10 + GLM-5.3-Flash subscription supported route + time 15:00-01:00 UTC campaign; conservative final cutoff 2026-10-06T16:00Z. No entitlement assertion from alias/model name alone, never redeem banked resets.

Admission: atomic sum of live reservations, requested worker memory <=1500MiB and host available minus reservations and requested budget >=10GiB; actual target cwd and TMPDIR filesystem >=50GiB + active disk reservations + 512MiB spike; use owned root .local/tmp. Recheck selected quota at launch boundary and disk/memory. Set aplexer memory/pid caps, timeout process group, private logs 600. Starting CLI returns session identity; inside wrapper `aplexer whoami --json` must match expected tag/workspace. Do not forge identity env, --from or fake sessions. Native agent must itself perform first tool action creating incremental artifact, distinct from wrapper started marker. Missing first-action within deadline -> explicit stalled state plus bounded recovery; no fake success from process presence/stdout.

Durable lifecycle queued/reserved/starting/running/completed-awaiting-review/accepted/failed/blocked/launch-uncertain. Head reviews artifacts; exit zero != accepted. Record quota snapshots, decisions and rejection reasons, native identity, requested/observed model, actual usage native metadata or null, outcome and acceptance owner. Account percent delta is not task token use/cost. Include bounded JSON/JSONL export consumed by existing private metrics dashboard, hourly grouping in Berlin or explicit UTC+timezone; 24h coverage and gaps explicit. No public prompts/private logs.

Tests need adverse behavior (concurrent submit/launch exclusion, conflicting idempotency, path parent/child overlap/symlink, quota unknown/exhausted/Codex cutoff, reset missing, promotion boundaries, /tmp reject, resource reservation race, unknown native launch response retaining ownership, timeout recovery, evidence missing and duplicate usage). Include one genuine bounded launched useful task with first action, incremental artifact and reviewed result. Unit/dry-run evidence cannot claim real success.

Architecture inspiration: Heru README only (https://github.com/alexeygrigorev/heru, read 2026-10-04): separate engine/parser from launch profile, structured invocation argv, normalized event envelope, native continuation IDs and contract tests. No code copied. This project owns admission/task lifecycle above provider adapters, leaves quota measurement to quse and native durable messaging/session identity to aplexer.

Scope first working version: robust Grok+Ant actual launch then expand verified routes; unsupported routes explicitly blocked. Avoid abstraction sprawl. Do not edit existing collectors/services; emit file projection and coordinate consumer contract. Agent Branches source/backup owned by desktop integration agent; cooperate on exact commit checkpoints.
